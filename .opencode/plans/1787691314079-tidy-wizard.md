# Merge-friendly mac branch: rerere + comment cleanup

## Context

`mac` periodically merges `main` (WSL config) and re-adapts ~7 divergent sections in
`tmux.conf`. The current strategy — keep main's code commented out with
`# ----- Linux (main branch) -----` markers — does not reduce conflicts and has
already failed once: merge `3350329` replaced mac's active
`set -g @plugin 'omerxx/tmux-floax'` with a marker-only line and commented out the
floax config block. **tmux-floax is currently dead on this machine (Alt-f does nothing).**

Decision (user): keep two branches, enable `git rerere`, clean up comments
(delete main's code, short why-notes only). No changelog doc.

Why rerere works here: it hashes each conflict's both-sides content, so a recorded
resolution ("mac side wins") replays only for *identical* future conflicts. If main
adds new lines in that region, the preimage differs and git prompts again — nothing
gets silently dropped.

## Changes

### 1. Enable git rerere (both machines)

```sh
git config --global rerere.enabled true
```

Note: the first main→mac merge after this still needs one manual resolution per
conflict; that seeds `rr-cache`. All later merges auto-resolve the same conflicts.

### 2. Fix floax regression — `tmux.conf`

- Line 191: replace the dangling marker with the active plugin line + one why-note:
  ```tmux
  set -g @plugin 'omerxx/tmux-floax' # works natively on macOS (fails in WSL2)
  ```
- Lines 212–219: uncomment the `@floax-bind/-width/-height/-border-color/-text-color`
  lines. Delete the `set-hook ... scratch` line entirely (leftover from main's
  scratch-session popup; floax never creates a scratch session).

### 3. Delete main's commented-out blocks — `tmux.conf`

- Lines 85–93: `# ----- Linux (main branch): theme toggle via zsh functions -----`
  block (theme menu bindings). Delete whole block.
- Lines 226–230: `# ----- Linux (main branch): zshrc_term_borders -----` block
  (pane border style + run-shell). Delete whole block.

No replacement comments: the next merge's resolution (mac side wins) gets recorded
in rerere; the config a reader sees is exactly what the machine runs.

### 4. Simplify remaining mac markers — `tmux.conf`

Keep the one-line header comments (they carry the why), drop the
`# /----- macOS -----` closing lines at 167, 219, 235.

### 5. Fix stale comment — `scripts/theme.sh`

Lines 4–6 reference `origin/main:scripts/theme.sh`, which does not exist on main
(main's toggle lives in `~/.zshrc` as `zshrc_term_theme`). Replace with one tight
line that keeps only the surviving why:
`# Ghostty follows the macOS system appearance, so mode() reads AppleInterfaceStyle.`

### 6. Commit

```
fix(tmux): restore tmux-floax and slim branch-divergence comments
```

## Verification

```sh
git config --get rerere.enabled          # true
tmux source-file ~/.config/tmux/tmux.conf
tmux list-keys | grep -i 'floax\|M-f'    # floax Alt-f binding present
tmux show-options -g | grep floax        # @floax-* options set
```

- Press Alt-f: floating window appears.
- After the next real main→mac merge: `git rerere status` shows recorded
  resolutions; divergent blocks keep mac's version.
