# tmux shortcuts

Generated by `scripts/shortcuts.sh` on every config load; edit `tmux.conf`,
not this file.

Prefix is `C-a` — `prefix X` means press `C-a`, release, then `X`. Windows are
numbered from 1, panes from 1. Mouse is on: click selects panes, drag a
border to resize, the wheel scrolls and can enter copy mode, double-click
copies a word.

`prefix ?` lists every binding and `prefix k` opens a searchable popup of
the same; this file mirrors the live key tables.
